# D-001 · tokens.css 唯一调色板 + app.css 棘轮只紧不松

- **Status**: Accepted
- **Date**: 2026-09-21（棘轮机制更早，本条追认并汇总）
- **背景与约束**: app.css 是 11 个历史样式层合并的单文件，曾出现 hex 字面量 189 处、
  font-size 字面量 380 处、18 个断点值、跨层选择器无序增长。此前同一批令牌在多个文件
  各声明一遍，靠加载顺序决胜，"改了顶部却没反应"。

## 决策

- tokens.css 是颜色与字阶的**唯一真源**（`:root` 浅色 / `html.theme-dark` 暗色双区）；
  新颜色/新字号必须进 token，app.css 一律引用 `var(--*)`。
- app.css 内 hex 字面量、font-size 字面量、断点值全部清零/冻结，由
  `services/sim2real-web/ui-layout-invariants.mjs` 棘轮把守：**预算只许收紧，放松必须
  带证据注释**。11 个样式层横幅与跨层选择器预算同样锁定。

## 被否决方案

- 放任字面量 + 事后人工清理：清不动，且新代码持续引入。
- 复用主题可变 token（如 `--panel`/`--bg`）承载字面量迁移：暗色主题会被改值
  （var 主题恒定性不成立），必须用值逐字节相同的常量 token。
- 为省预算上调棘轮：实测发现计数漂移先复跑核实（并发会话中间态会骗过单次运行）。

## 后果与边界

- 新 token 名引用前先全仓 grep 是否为「已引用但未定义」的历史名——`var()` 静默回退
  会骗过所有人（案例：`--ink` 被占用，实际新增改名 `--warm-ink`）。
- 批量替换脚本必须在**同一坐标系**一次性右到左应用（曾在第一版因坐标漂移写坏层横幅）。

## 失效/重审条件

仅当出现经确认的设计系统重写时，以新决策废止本条；棘轮数值调整（只紧方向）不需要重审。

## 守卫

`ui-layout-invariants.mjs`（唯一真源）/ `npm run verify:ui` / `.githooks/pre-commit`。
