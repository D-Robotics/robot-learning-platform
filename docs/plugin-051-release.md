# 插件 0.5.1 联动验收记录

本版把 Studio、Qoder 和学习平台连接到同一份明确实验：平台保存当前账号的训练与同源评测引用，客户端重新验证权限后接续原任务。默认展示参考观察、训练、评测和结果；单变量调参是可选后续。

## 本版变化

- 增加 owner-scoped 实验会话及带游标事件接口，旧平台继续使用按平台与账号隔离的本机引用。只读恢复不会创建任务或迁移引用。
- 增加共用实验页：真实训练奖励曲线、两组同条件比较、明确评测的视频播放器和 JSON 导出。终态停止事件订阅；重新连接成功后清除重连提示。
- 支持显式协商的 MCP Apps 资源，使用官方 SDK、自包含资源与受限 CSP。面板通过只读工具取数，播放与保存交接到同一平台实验页，不传递平台 Cookie。
- 提供中文简短回执；文本宿主仍能读到准确任务引用，完整结构化诊断按需保留。恢复 OriginMan 实验后重新建立课程上下文，避免误走真机遥测渲染。
- 对齐安装、教程与技能指引：完整 Workshop 先实际观察参考；保存评测记录是文件导出，制品晋升属于另一项操作。通用场景与硬件验收说明按需读取。

## 已执行验收

macOS 上使用 RDK Studio 1.5.1、Qoder 0.5.3 实际加载插件 0.5.1，核对运行来源，分别完成参考仿真、8192 步 CUDA 短训练、同源评测、曲线与比较页和 6 秒回放。Studio 的部分页面操作由验收操作者在内嵌工作台点击确认；不将工具返回链接当成实际播放。

两轮短训均如实保留未达收益判据的结果：公开条件组为原 PD 13/31、调参反馈 13/31、本次 RL 1/31；补充条件组为 13/31、17/31、1/31。执行完成与效果改善分别报告，不因流程通过而声称策略提升。

Studio 实验已在 Qoder 恢复并核对相同训练、评测与权重，未重新训练。另用空本地引用目录从真实平台恢复已存在实验，验证接续不依赖原电脑聊天记录。JSON 导出已实际保存并核对明确任务。

官方 MCP Apps SDK 沙箱已验证协议连接、曲线、只读刷新及同一实验页交接按钮。这属于 SDK 集成验收，不代表上述原生宿主已支持内联 MCP Apps。

专项检查包括插件契约 128 项、实验恢复 20 项、共用界面 7 项、实验 API 与 RBAC 17 项，以及分发包实际认证模块的 18 项授权恢复门禁。分发验收同时覆盖成功路径、失败禁止重交、跨 MCP 重启恢复和权重冲突拒绝。

## 范围与门禁限制

本轮未做 Windows 原生实机验收，也未做机器人运动或真机效果验收。提供 Windows 安装入口及对应协议测试不等于 Windows 实测通过。宿主模型仍可能展开阶段说明；共用实验页和工具中文回执提供稳定结果入口。

`npm run verify` 已执行，但在 `verify:engine-locks` 停止：8 个 Python 引擎锁与当前解析结果不一致。使用改造前提交 `dadc25b` 的脚本及全部 20 份 requirements 输入复现相同失败，21 个输入文件与本分支一致。本版未调整这些训练依赖，不能将完整仓库门禁记为通过；该项需单独维护。

接口与分层设计见 [插件、IDE 与平台的统一体验](plugin-host-integration.md)。学员教程随完整插件包交付，原始分享包不包含个人登录、资源绑定或本机路径。
