# OriginMan 厂家确认与真机验证清单

本清单独立于离线仿真研发。已有模型、编号图、标定读取接口和控制协议足以开始
模型适配与训练；以下事项用于确认模型和实物一致性，并建立可信的迁移条件。
没有现成报告时，可由双方测量补齐，不把它们全部视为厂家缺交文件。

## 请厂家提供或确认

| 事项 | 需要的内容 | 解决什么问题 |
| --- | --- | --- |
| 样机与模型对应 | 实际机械、主控、镜像、控制板固件和 SDK；模型与电池相机配置的对应 | 模型是否代表准备开课的机器 |
| 关节装配约定 | 已有映射、安装正方向、模型零位、装机限位与推荐站姿 | 连续关节目标能否正确转换为舵机命令 |
| 固件控制语义 | 目标覆盖或排队、插值、运动时间、停止、断连和回读调度 | 如何实现策略循环和异常处理 |
| 执行器与 IMU | 实际型号、IMU 坐标、量程和上报设置；已有负载响应记录 | 执行器近似和观测坐标是否合理 |
| 现有工程入口 | 若已有仿真或 RL 工程，提供代码、依赖、权重和复现说明 | 减少重复研发；无现成成果则我们开发 |

公开编号、零偏与限位回读能力由我们先整理，每台零偏从本机读取。
不要求厂家重新制作所有公开材料，也不要求先交付一套强化学习平台。

## 待真机验证

| 阶段 | 需要记录 | 进入下一阶段的条件 |
| --- | --- | --- |
| 关节核对 | 保护条件下小幅目标、位置回读、方向、零位与限位 | 映射表和实际运动一致 |
| 闭环时序 | 全腿读写和 IMU 并行的周期、延迟、抖动、丢包与数据年龄 | 据实确定策略频率和超时策略 |
| 负载响应 | 电压、负载、目标和实际角度、滞后、死区与回差 | 修订执行器近似和允许残差范围 |
| 姿态与推理 | IMU 姿态估计、航向积分及漂移、板端推理和循环耗时 | 仿真观测能由真实数据形成 |
| 步态迁移 | 保护条件下站立、参考迈步、同条件 RL 对照 | 先证明参考可重复，再判断策略收益 |
| 应用验证 | 起停、目标丢失、退出、视觉与步态并行；之后扩展转向 | 只展示经过验证的跟随范围 |

仿真中的理想姿态、力矩限制、摩擦和控制周期不作为真机实测数据。
异常情况下的停止、保姿或支撑保护需要实测；不能默认断电对双足最安全。
本轮不发送任何设备运动命令，也不将仿真策略标为可部署。

## 原地反馈参数RL原型

该原型已在仿真中学到两个踝反馈参数。运行时使用侧倾角与相应角速度，以20ms
周期形成连续位置残差；其他关节保持参考站姿。它不需要厂家代交RL权重，也不以
力矩控制接口或足底传感器作为启动验证的前提。

实际联调仍需确认两个踝侧摆轴的ID、方向、零位和限位，核对IMU侧倾角与角速度
的轴向、单位和估计延迟，并测量位置目标的执行与覆盖时序。控制系数、0.3rad
仿真残差上限及20ms周期均未经样机验证，不能直接作为实物允许值。参数学习的
仿真结果不替代参考站姿、实物负载响应、足底接触与同条件恢复的真机核验。

## 连续髋踝修正原型新增事项

后续神经策略已在仿真中取得超过冻结基础反馈的收益。它每20ms读取14维状态，
输出两个连续修正，映射到左右四个髋踝关节；需要打包固定反馈、输入编码、动作
映射与ONNX，不能把两个输出直接当成完整关节位置下发。

除前述IMU核对外，需确认四个髋踝关节的回读单位、方向、更新时间和时间戳；
没有直接速度回读时由我们实现并验证速度估计。实际姿态估计、数据年龄、延迟和
连续目标执行周期需要实测；当前理想观测和20ms周期不是厂家能力声明。
0.12rad、0.20rad额外修正和0.3rad总残差均只是仿真配置，不能直接用作实机限值。
原地站稳、迈步迁移、人体跟随仍分阶段验收，本轮未发送设备运动命令。

## 当前受扰行走候选所需的具体信息

候选使用10个腿部关节的位置残差，基础迈步来自参考轨迹。正常行走保留不能单独
算作RL收益；尚须证明受扰后恢复并继续前进。已有一个改善例子，也有退化条件，
目前不满足演示采用条件。

请厂家确认以下信息，不要求厂家代做RL训练：

|确认项|我们拿来做什么|
|---|---|
|这台样机对应的模型版本、相机和电池装配|确认质量惯量、脚底和重心代表实物|
|腿部关节的实际ID、安装方向、模型零位和限位|将10维关节残差转换成正确的舵机位置；公开编号资料先由我们整理|
|目标持续时间、覆盖/排队和回读语义|确定每次控制输出如何执行，避免使用旧状态或积压目标|
|IMU轴向、单位、上报频率及已有姿态接口|形成策略和接管逻辑所需的重力方向、角速度和航向估计|
|实际舵机型号、固件版本及已有负载响应资料|确认执行器模型；没有实测记录时由我们拿样机后测量|

当前仿真为20ms控制周期、位置残差上限约0.2rad；接管阈值侧倾0.13rad、
侧倾角速度1.3rad/s。这些仅是实验配置，不是实物允许范围或厂家指标。实际
循环周期和传感数据年龄必须测量；不能达到该周期时，要重新适配和训练。

真机记录至少应有：主控单调时间戳、命令序号、目标角度、实测关节角度、
IMU原始值和姿态估计、数据接收时间、供电状态。速度可由有时间戳的关节回读
估算，但要保留估算方式与延迟。没有硬件时间戳时，主控接收时间不能冒充采样时间。

先核对关节与传感、复现参考步态，再进行同条件的RL对照。人工随手推动不能
直接与仿真的牛顿数比较；需要可重复的扰动记录。若参考动作无法重复，先处理
机械、标定和时序，不把失败直接归因于强化学习。
