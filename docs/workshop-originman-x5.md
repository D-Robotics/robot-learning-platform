# OriginMan Workshop：步态强化学习与人体跟随

## 当前结论

选用基础版继续技术预研，保留关节级步态强化学习。当前最值得验证的候选是“参考迈步中受到侧向扰动，RL协调腿部关节恢复并继续走”。基础迈步由参考轨迹提供，RL学习失稳时的关节修正，不能说成整套步态从零学会。

原地连续控制已出现可重复的仿真收益：固定基础反馈13/31，叠加每20ms的神经髋踝
修正后，三个独立种子分别28/31、28/31、22/31。实时策略明显超过固定输出与冻结
身体观测的对照；无扰动站立保留，仍有失败和两个退化条件。它可作为连续控制RL
仿真例子，过程与边界见[连续髋踝修正验证](originman-continuous-residual.md)。

迈步中的抗扰收益尚未稳定，真机尚未验证。原地成果不替代本方案保留的步态RL
目标，下一阶段才是将残差结构接入参考迈步、重新完成同条件评测与实物核验。
参数学习与变力度踢球保留为独立教学备选，不能据此宣布整场课程已经验收。

当前完整结果与判据见[能力验证记录](originman-rl-validation.md)。厂家确认和真机事项见[独立清单](originman-confirmation-and-hardware.md)。不能用一段成功视频、训练奖励或ONNX导出成功代替能力验收。

## 三个版本

以下时长是课程编排目标，尚非整班实测用时。三版都保留腿部关节RL；深度和学员独立完成范围不同。均须先完成课前研发与真机验收。

|版本|课堂目标|强化学习部分|最后的实物环节|当前状态|
|---|---|---|---|---|
|完整，6–8小时|模型、奖励、训练、评测、迁移全过程|学员比较奖励和参数，训练或继续训练10关节残差策略，检查未见条件和失败案例|演示通过验收的RL策略；再独立运行官方人体跟随|研发目标，不能承诺现场从零训练出真机步态|
|基础，约4小时|看懂并修改一条完整链路，看到可重复的前后差异|使用核实模型和固定训练配置，改一项奖励继续训练，比较参考、简单反馈和RL|只有验收通过后才展示RL真机动作；人体跟随为官方应用独立演示|当前选定的预研路线；效果与实物均未验收|
|简略，约2小时|理解腿部RL如何改变物理动作|保留小规模训练和评测；主要使用预先验证的权重、轨迹与失败回放|展示已验收权重和官方人体跟随，明确与学员当场产物的区别|不承诺学员独立从零完成训练或迁移|

简略版并非取消步态RL，也不把调用现有动作组当成RL学会行走。若预训练策略本身没有可重复收益，三版都不能以“训练跑通”宣布动作目标完成。

## 基础版课堂主线

1. 核对机器人模型与关节，理解参考迈步、位置舵机和地面接触。
2. 运行同一参考步态，展示足底接触、姿态和前进距离，解释机器人本身已有的稳定性。
3. 加入公开配置的侧向扰动，比较参考和简单IMU反馈，找出真实失败条件。
4. 检查策略观察、关节残差、奖励和训练曲线；修改一项配置，创建有父实验关系的新训练。
5. 固定最终权重，在预先声明的条件下评测。保留所有失败，检查是否只是少走、慢走或停住。
6. 回放完整物理轨迹和关节目标，定位成功和退化；仅在通过单独真机验收后展示实物RL动作。
7. 释放RL控制出口，再运行官方人体跟随。它是独立应用演示，不能标为RL策略已完成视觉跟随。

期望的可见收益是“同样的扰动使参考步态跌倒，RL恢复后继续走”。仅完成蹲起、抬脚、静态站稳，或精度只改善毫米级，都不足以满足本次课程目标。

## 为什么目前不能承诺更好的效果

|限制|目前的影响|需要补齐|
|---|---|---|
|收益尚不稳定|一个恢复例子不能代表全部条件；仍有退化|完整预声明条件、多种子和跨参数结果|
|接触及执行器未实测|姿态、恢复时机和足底支撑可能与现实不同|样机参数辨识和未参与标定动作的对照|
|姿态及关节观测理想化|仿真状态不能直接当作板端现成输入|IMU坐标与姿态估计、回读时间戳、延迟和速度估计|
|步态只验证直行与侧向扰动候选|不能扩称任意转向、追球或自主视觉跟随|独立任务研发与真机验收，不能靠增加课时自动获得|
|现场时间有限|短课不适合承担模型标定和大规模训练的不确定性|课前验证、预训练权重、明确现场训练范围|

## 验收和开课条件

- 正常行走不明显退化；相同条件下有清楚且可重复的RL收益，并保留全部失败结果。
- 对步长、控制周期、接触和执行器变化有明确适用范围，不能只在一个精确参数点有效。
- 真机完成关节、时序、执行器和观测核对，再完成参考与RL同条件对照。
- 人体跟随完成独立验收，并在切换时只有一个模块持有运动控制权。
- 整场彩排通过，教材、模型、权重和实验记录能对应同一版本。

当前继续推进仿真验证。拿到样机和校准证据前，不标记为已落地；若RL收益仍无法稳定复现，就不将该动作作为课程卖点。
