# Workshop 短指令与自由探索

目标：学员在空白对话只说“带我开始 Workshop”，即可进入工作台，通过下一步按钮完成参考观察、明确选择训练预算、训练、同源评测和回放。技术标识由系统管理，不靠长提示词维持流程。

默认入口 `rdk_workshop` 支持开始、继续、查看效果。开始仅准备当前账号可见的课程模型与明确算力，不启动训练。默认界面同时提供 8192 步快速体验、50 万步正式实验与自定义参数；快检按钮显式授权训练及后续同源评测，正式或自定义先展示确认配方。没有点击预算就没有训练。

平台按账号保存课程草稿、参考观察方式、冻结参数、当前所选实验、原训练与评测引用。另一软件说“继续”恢复当前选择；多个历史实验通过卡片选择，不猜全局最新 Run。旧版本实验仍可选取查看。切换和恢复不提交训练。

浏览器通过持久化单次步骤 claim 取得正常 `/runs` API 的提交请求。业务校验、权限、配额与资源门禁仍由原有 API 执行。多个窗口只有一个能取得提交请求；回包丢失后按同一账号、同一幂等键恢复已存在 Run，状态不明时只读恢复，不重交。失败、空结果、未认证和来源不符都显示实际阻断。

“暂停后续自动步骤”阻止新的自动评测，不取消已经提交的训练。恢复评测需要明确点击。新实验保留旧实验；不允许用同一实验改参数。退出或关闭页面不会取消 Worker，重开原页面后继续。只有实际播放才显示播放进度；已录制不等于已播放，快检完成不等于策略提升。

自由度：默认课程路径不会拦截用户明确的解释、资料、其他机器人、引擎或高级训练请求。原子 MCP 工具仍在；页面提供预算、seed 与训练侧推上限，更多配方通过主工作台或自然语言选择。范围沿用当前仅仿真课程，不扩张硬件资格。

Qoder 直接使用内置浏览器工作面：模型只负责打开入口，用户通过产出中的“网页查阅”展开可见页面。Studio 使用右侧工作台。MCP Apps 仍保持只读视图，写操作留在同源平台页面；不为按钮扩大沙盒权限。

验收同时检查：零预算不提交、并发不重复、未知状态不重交、暂停可恢复、账号隔离、跨进程当前实验一致、旧实验可读、自定义配方不扩预算、真实曲线采样点交互、真实播放器进度。最终用空白 Qoder 对话的唯一提示“带我开始 Workshop”完成一次新的快速体验，记录真实执行与未提升结果。
