# OriginMan Workshop：工作台纯仿真流程

OriginMan原地受扰恢复现在有独立的页面入口，位于“训练与策略”中的
“OriginMan Workshop · 受扰恢复强化学习”。页面复用平台的模型登记、账号隔离、
Run、幂等提交、受控本地Worker、日志与制品校验。训练、评测分别生成Run，
评测明确关联本组训练；页面不填入课前权重的历史成绩。

这条流程使用专用契约`custom-policy-originman-recovery-v1`：14维观测，两个髋踝
连续修正，50Hz。它与旧的41维观测、10关节步态实验分别运行。
没有接设备，也不产生硬件部署资格。

## 学员在页面上做什么

1. 修改训练控制步数、随机种子、训练侧推上限。基础PD、奖励、动作映射、控制周期
   和31个课堂评测条件保持固定；改配置后创建新Run，不覆盖原策略。
2. 点击“创建本组训练”。页面自动登记专用模型契约，向所选Worker提交真实SAC
   训练，显示状态、累计控制步、奖励曲线、最近开发检查与原始引擎日志。
3. 训练完成后，在“本组训练记录”选中该次实验，点击“评测所选权重”。评测使用
   这份训练的模型、初始策略、最终ONNX和冻结配置，不读取当前表单的新值。
4. 查看基础、未训练、训练后和冻结输出的31条件对照。页面展示改善、退化、
   身体倾角、实际额外髋踝目标，以及本次轨迹的四组物理回放。
5. 下载本次评测JSON。刷新页面后从账号内的Run重新恢复记录，旧实验仍可选择。

正式主实验请求500,000步，训练器实际完成500,224步。4096至1万步仅用于检查
软件链路，不能承诺学好；公开课堂基准可重复用于练习，不作为新的未见测试证据。
每个回合6秒，最终稳定判据和明显收益判据沿用
[连续髋踝RL实验](originman-continuous-residual.md)。

## 课前启动独立工作台与真实Worker

准备调用方提供的适配模型`scene.xml`及其`meshes/`，并安装仿真依赖：

```bash
uv venv --python 3.12 .eval-venv
uv pip install --python .eval-venv/bin/python -r engines/originman-straight/requirements-sb3.txt
node scripts/dev-originman-workshop.mjs \
  --scene artifacts/originman-straight/push-model-01/scene.xml \
  --python .eval-venv/bin/python \
  --data-dir artifacts/originman-workbench-classroom
```

模型路径为本次研发工作区示例，讲师按实际位置替换。可用`--font <中文字体文件>`
生成中文字幕；未配置时视频使用英文标签。原始厂家资产不随公共仓库重新分发。
本机还需可用的MuJoCo离屏渲染与ffmpeg。渲染失败时数值结果保留，页面明确提示
本次无视频，不调用旧视频冒充当前结果。

启动器建立全新的隔离目录，在回环地址运行工作台和真实CPU Worker，随机选择
端口及内部令牌，打印页面地址。它不读取`.env`来启动，也不改变已有平台进程的
账号设置。界面为独立本地开发实例，不能将此启动方式用于开放网络的多用户生产环境。
停止后保留台账与训练目录。如需验证恢复，在原命令上增加`--resume`，新进程
会恢复原有记录；不要在有任务运行时停止服务。

在已有服务中使用时，由管理员将下列引擎注册到已有真实Worker，并为该Worker配置
`ORIGINMAN_SCENE`和Python依赖。工作台照常保留自己的认证、权限和存储配置：

```json
{
  "originman-recovery": {
    "executable": "<Python解释器绝对路径>",
    "args": ["<仓库绝对路径>/engines/originman-straight/workshop_adapter.py"]
  }
}
```

这是`RDK_SIM2REAL_TRAIN_ENGINES_JSON`的一个条目，合并到已有配置，不能覆盖其他
引擎。模型路径由受信Worker环境提供，页面不能指定任意服务器文件。

## Run与可追溯数据

|位置|记录内容|
|---|---|
|平台训练Run|表单冻结配置、引擎、模型、执行资源、状态、原始日志与进度、策略SHA-256|
|平台评测Run|父训练Run、本次同条件结果、选例规则、曲线、视频摘要与策略SHA-256|
|Worker训练目录|模型与源码快照、初始/最终权重、检查点、逐步日志、训练及SB3完整性清单|
|Worker评测目录|31条件×5控制器的完整轨迹与决策日志、评测源码快照、数值摘要和视频|
|页面下载|当前训练和评测的Run记录及对照，不包含厂家模型资产|

模型契约占位文件只是登记入口，不代表已经有策略。训练完成后才生成本组ONNX。
Worker对制品清单和策略字节进行校验；视频读取另核对摘要与字节数。
评测只能引用同账号、同模型、同Worker且已完成的训练，不能注入其他账号的路径。

## 失败、重试与课堂兜底

训练或评测失败时保留Run和原始日志。先查看错误，再修复依赖、模型或资源；
不要删除失败记录。任务运行中页面会阻止重复提交；网络响应不明确时，本页重试
沿用同一个幂等键和冻结请求，不自动创建另一个任务。
当前未提供在页面强行中断训练的按钮；关闭页面不终止Worker任务，回来后可继续查询。

短训练未达到判据时，仍显示真实的恢复数、全部退化和失败。讲师可在
已有完整实验之间选择，但要明确区分学员现场训练与课前权重。
原地恢复流程不自动代表步态RL、人体跟随或真机迁移完成。厂家与实物事项继续见
[独立清单](originman-confirmation-and-hardware.md)，课程编排见
[4小时Workshop](workshop-originman-basic.md)。
