# Workshop 数据、资源与入口体验修正

## 范围

默认 OriginMan 受扰恢复课程；不改变训练配方、历史原始结果、质量阈值或真机资格。

- 通用工作台旧版摘要也使用逐条条件重算受扰恢复，并单列无扰站立；以实际加载的内容哈希脚本生成允许列表补丁，保留其他线上逻辑。
- 效果表从逐条有限数值 force 和三种控制器的布尔结果统计；force≠0 才计入受扰恢复，force=0 单列无扰站立。缺少逐条证据时保持未验证，不用汇总数倒推。
- 学员资源列表排除离线、Mock、浏览器本地 Agent 和未明确登记 recovery-reflect 引擎的资源；提交前仍刷新健康并检查课程环境，不自动选择算力。
- Worker 增加经原有认证和账号检查的只读课程预检，使用受信任解释器与独立探针，限制时间、输出和继承环境；忙时拒绝，不执行训练命令。检查原场景、依赖、观测/动作、ONNX、源码输入和 CUDA 运算。
- 独立结果页提供回到相同 context 的课程入口。JSON 和视频建议名包含 context，避免不同实验互相覆盖。
- 新实验预览不读取账号数据或创建实验；普通聊天入口先返回可点击课程链接，用户点击后进入，不等待三步浏览器编排。明确要求自动打开时仍保留导航方案；已有实验继续按原身份恢复。

## 验证

`npm run verify:ui`、`npm run verify:plugin:contracts`、课程路由与跨轮比较测试、Worker 预检/执行器测试、`npm run build` 和 `npm run verify:security`。发布包必须核对 FILES.sha256、wrapperSources 与真实宿主登记版本。

回归包括零扰动力排除、不完整逐条证据拒绝、非课程 GPU 排除、预览不访问授权/账号数据、同 context 返回和包含实验标识的下载建议名。原 Worker 的额外视频接口通过允许列表补丁保留，不以旧源码整包覆盖线上运行时。

## 已知宿主边界

Qoder 的模型推理耗时和英文思考摘要由宿主控制。减少工具往返不证明端到端延迟已经改善；须记录同一宿主/模型的实际测量，不能仅靠提示词宣称隐藏了内部推理。本轮详细实验、部署摘要和现场观察保存在独立验收产物中。
