# 机器人学习平台插件 0.3.1 体验教程

适用：RDK Studio 桌面版、0.3.1 便携分享包、OriginMan 受扰恢复仿真。更新日期：2026-11-04。无需机器人或板卡。

学员只需安装、确认账号，再输入一句话。教师需要提前准备账号权限与在线课程资源；插件不会自动开通算力。建议预留 15–30 分钟完成首次体验，这不是训练耗时承诺。

## 1. 解压与安装

把分享包完整解压到最终保存位置，进入 `plugin` 目录：

- macOS：双击 `setup-macos.command`。
- Windows：双击 `setup-windows.cmd`。

安装器会准备兼容 Node、核对下载摘要并配置学习平台连接，无需 npm install、管理员权限或手写 Cookie。下载失败时先处理显示的网络错误。不要只解压单个脚本；移动目录后重新运行安装入口。

安装器显示插件版本与更新的连接名。出现多条同类连接时明确选择本次课程连接，不随意覆盖其他连接。Studio 正在运行或宿主版本不兼容时，按安装器提示处理；不要强行修改文件或结束正在执行的任务。

支持登录继承的 Studio 使用当前任务账号。其他宿主按浏览器授权提示确认账号和连接码。无需提前访问学习平台，但必须已有统一账号与相应权限。密码、Cookie 和私有会话文件不要发进聊天。

先输入：

> 使用机器人学习平台插件检查接入，报告当前账号、认证模式、实际加载的插件版本和课程资源。只查询，不提交训练，不操作板卡。

通过标准：账号正确，目标平台正确，实际加载版本为 **0.3.1**，`loadedSourcesMatch=true`，有当前账号可见且在线的课程资源。若仍显示旧版，刷新对应 MCP 连接并在新任务复核。仅看插件中心版本号不能证明旧进程已经更新。

完整安装与教师资源配置见[首次使用说明](../plugins/rdk-robot-learning-platform/references/workshop-first-run.md)。仓库源码模板与已经打包的便携插件是不同安装形式；首次体验使用本次分享包。

## 2. 学员输入一句话

在 Studio 新建任务，输入：

> 帮我用机器人学习平台插件做一次 OriginMan 受扰恢复短训练，训练完评测并播放本次回放。

正常顺序：**检查 → 训练 → 同源评测 → 打开回放**。学员无需填写模型 ID、Run ID、算法或资源参数。若有多个课程资源，按名称选择一次；不要让 Agent 自动换机器。

固定短训为 SAC、8192 步、种子 7、推力 8.1、GPU，仅仿真。资源不可用时停止并联系教师，不静默改用 CPU。训练和评测各提交一次；失败、断线或重复点击后保留原实验，不换标识重交。

不通过：要求学员编写 UUID、改 manifest、重填技术参数；任务失败后自动换资源或重新训练；没有实际查询就声称完成。

## 3. 查看评测与真实效果

完成后可输入：

> 展示本次实验的训练和评测引用，核对父 Run 与策略摘要。分别报告 historical、additional 中 original、tuned、本次策略的恢复数，以及 clearGain。只查询已有结果，不重新提交。

通过标准：评测对应本次训练，父 Run 正确，策略摘要一致，两套对照数值与平台结果一致。

`completed` 表示执行完成，不代表策略更好。2026-11-04 已有真实验收的这次 8192 步短训结果如下，仅作示例，你的实验以实际回执为准：

| 套件 | original | tuned | 本次 RL |
| --- | ---: | ---: | ---: |
| historical | 13/31 | 13/31 | 6/31 |
| additional | 13/31 | 17/31 | 11/31 |

本次 `clearGain=false`，未超过基线。不能把参考策略说成刚训练的策略，也不能降低评测门槛。调整参数应由用户明确发起新实验。

## 4. 确认视频真的播放

若播放器没有自动打开，输入：

> 打开刚才这个实验的准确评测回放，使用已有视频入口，不重新训练或评测。不要用网页正文抓取或真机遥测渲染代替回放。

在 Studio 播放器点击播放，检查：

- 打开的是本次评测的视频。
- 时间从开头推进，机器人画面随时间变化。
- 播放至结束，没有错误页；视频时长以实际播放器为准。

已有验收视频实际播放至 0:06。只有链接或 HTTP 200 不算播放通过。`playback.state=recorded` 表示有历史视频回执；`endpointVerified=false`、`verifiedInPlayer=false` 表示插件尚未观察端点或播放器，不等于视频失败。

若缺视频、Worker 离线或媒体无法读取，保留原评测和数值结果，让教师处理原连接，再打开同一视频；不重提评测掩盖问题。

## 5. 换对话恢复原实验

先保存本轮回答中的实验引用。新建任务，输入（替换尖括号）：

> 用同一个机器人学习平台连接恢复实验 <本轮实验引用>。只读取原训练和原评测的当前状态，打开原回放，不选最新任务，不重新提交。

通过标准：恢复前后的训练 Run、评测 Run 完全相同，没有新增任务。恢复依赖本机私人引用和当前账号；换电脑不会自动同步。

可选失败检查：要求恢复一个明确不存在的实验标识，应提示未保存；随后仍能恢复原实验。不要为了测试故意断开共享 Worker，也不要额外创建训练。

## 6. 常见卡点

| 现象 | 处理 |
| --- | --- |
| 未登录或会话失效 | 在当前 Studio 账号入口登录；其他宿主完成浏览器授权 |
| 网络超时 | 保留登录与原实验，恢复连接后查询原 Run，不换标识重交 |
| 没有课程资源或资源离线 | 联系教师分配或恢复当前账号可见资源，停止提交 |
| 课程契约不匹配 | 把原错误交给维护者；学员不自行改 manifest |
| 训练或评测失败 | 保留原 Run 和日志，停止自动重试、换机器或改参数 |
| 视频打不开 | 核对原 Worker 与宿主网页登录，保留原评测，不重新训练 |
| Studio 只提供视频生成工具 | 新建任务明确说“机器人学习平台插件软件诊断”，先核对连接；已有回放不是创作生成 |
| Studio 显示“结果尚未验证” | 分别核对平台 Run、评测结果和播放器，不以宿主提示替代这些证据 |

提交结果未知时，不要要求“重来一次”。先恢复同一实验，查明是否已有 Run。Agent 回复结束也不代表后台任务已经取消。

## 验收范围

0.3.1 已在一个正式 macOS Studio 账号和已配置课程 Worker 下完成学员一句话的新训练、同源评测、视频播放。107 项契约测试、15 项实验引用测试及便携通信夹具检查通过；夹具通过不替代真实训练或视频验收。

Windows 仍只有代码与模拟验证；双真实账号交叉越权、整班并发、全新电脑首次体验、常驻算力，以及真机部署、板端调优和回滚仍待专项验收。Studio 的分支选择、过程展示和播放器状态反馈仍需宿主配合。后续平台预检改动不包含在这份 0.3.1 分享包中。

开发者与教师参考：[交付范围](plugin-031-delivery.md)、[接入与实验引用](plugin-experiment-handoff.md)。
