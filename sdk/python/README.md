# Python SDK and CLI

No third-party dependency is required. From the repository root:

```bash
PYTHONPATH=sdk/python python -m rdk_robot_learning.cli health
PYTHONPATH=sdk/python python -m rdk_robot_learning.cli overview
```

Set `RDK_SIM2REAL_URL` and `RDK_SIM2REAL_TOKEN` for a remote deployment.
