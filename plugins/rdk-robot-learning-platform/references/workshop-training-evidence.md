# OriginMan 快检与正式效果实验（项目实测）

这是项目仿真实测，不是官方性能承诺，不是实体抗扰证据。历史对照与学员本组本轮成绩须分别标注。

## 学员选择与完成标准

- 8192 步快检：验证提交、训练、同源评测、结果接续与回放链路。策略可能弱于基线。流程完成不算效果达标。
- 500000 步正式效果实验：用于同条件比较原 PD、调参反馈与本次 RL。执行完成后仍须核对本次策略来源与评测；未达到收益判据就明确未达标，不能因耗时长或训练 completed 而通过。
- 未选择：只问一个中文预算题；“不清楚”先解释并暂停，不默认提交。已明确预算不重复问；换预算须新实验，保留旧结果。

## 追溯与课堂防错

用平台返回的原实验引用恢复，不手抄、猜测或按全局最近 Run 找任务。查询404、断线或引用保存失败不代表 Worker 已停；不得因此重复提交。按原 Run 只读恢复和增量日志核对。列表可能分页，单次日志可能被截断，不把一页当全量。

优先打开已绑定实验页核对本轮训练、同源评测、曲线与视频。初始视频时长0不等于损坏，等待播放器就绪并观察时间推进；链接存在或打开页面不算播放成功。保存文件要核对字节与回执，不能把旧回放装成本轮媒体。

课堂报告分别说：流程是否通过、仿真效果是否达标、真机是否验证。当前本条预算对照只验证固定 seed 和已知仿真条件，实体扰动恢复仍未完成。

## Qoder 回放的宿主差异

本轮桌面观察：模型的外部 Browser Connector 未连接，不能自动播放。任务右侧“产出→网页查询”中的本轮实验页可点开 Qoder 内置浏览器，人工点击播放器后实际播放到6秒结束。该入口补验不等于模型自动播放通过；没有实际播放时应写“训练与评测完成，回放待验”，不能写完整流程通过。不因连接器故障重训或重新生成视频，也不要求登录 Qoder CLI 来替代宿主连接问题。
