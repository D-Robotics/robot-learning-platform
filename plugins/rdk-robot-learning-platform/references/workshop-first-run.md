# OriginMan 受扰恢复 Workshop 教程 · 0.6.39

本页介绍一门示例课程。通用仿真、训练、评测和部署入口见[插件使用说明](user-guide.md)。

## 安装

先解压到以后保留的目录，不要从 ZIP 内运行。

- **RDK Studio / macOS**：双击 `setup-macos.command`。
- **RDK Studio / Windows**：双击 `setup-windows.cmd`。
- **Qoder / macOS**：双击 `setup-qoder-macos.command`。
- **Qoder / Windows**：双击 `setup-qoder-windows.cmd`。

安装器自动准备兼容 Node，核对下载摘要，仅配置本插件，保留其他连接与备份。Qoder 安装器会生成 `Qoder本机导入包.zip`，在桌面“扩展→已安装→添加→上传 Plugin”导入这个本机包。原始分享包用于分发；本机包包含本机路径，不转发。无需平台源码、npm install、密码或 Cookie。

首次打开先看参考。准备动手时点「开始实操」。如果工作台尚未登录，点「登录学习平台」，登录成功后，同一个标签页会直接回到 Workshop 选算力。点「检查这台算力机并继续」会检查所选机器的连接和本课程需要的 CUDA 环境。检查通过后进入预算页。点「开始快速体验」才会开训，正式和自定义预算会先请你确认配方。如果当前平台不提供课程环境检查，页面会明确标记「课程环境未验证」，由你决定是否继续选预算。跨软件接续需使用同一个学习平台账号。

## 一句话开始

新建空白聊天，只输入：

> 带我开始 OriginMan 受扰恢复 Workshop

助手先介绍课程。有已选实验时，可以直接打开它。首次实操按页面按钮登录、选择算力机。板卡在「连接设备」中单独管理。Qoder 页面未展开时，点任务右侧“产出→网页查阅”；Studio 看右侧工作台。不需要发工具名、实验 ID 或长提示词。

如果当前要训练 OriginMan 强化学习跳舞，明确说“训练 OriginMan 跳舞”。插件会使用独立 Dance PPO 流程，不进入或沿用受扰恢复课程。当前对话已经确认的舞段会继续沿用；新一轮使用新的实验上下文，继续已有一轮只读取原 Run。提交后自动打开平台本轮 Run 详情；若宿主不能自动导航，回复里会保留可点击的运行链接。

舞蹈算力选择会显示 Worker 最近上报的引擎和 Mock 状态，并优先列出支持 `originman-dance-ppo` 且非 Mock 的资源。能力未知的机器先点「测试连接」刷新清单；提交前还会再次验证所选 Worker。若当前平台没有提供绑定 Run 的舞蹈视频地址，结果页会明确说明回放暂不可播放。

1. **看参考**：点击讲师参考回放，结束后自动显示预算选择。也可明确点击“跳过参考”，或打开参考仿真自由探索。参考不算本次训练结果。
2. **选一次预算**：点击“开始快速体验·8192步”，即开始训练与后续同源评测。50 万步或自定义参数会先显示确认配方。未点击预算不会训练；不会自动扩大预算。
3. **等本次任务**：页面持续读取原训练，完成后自动评测同一策略；无须继续发“查一下”“做评测”等提示词。打开「查看实时曲线」可读采样点和曲线解读，运行日志在「更多操作」。用「在新标签查看运行记录」打开记录，原实验页会保留。
4. **看结果与回放**：点击“查看对比与回放”定位结果，页面只有一条滚动面。评测完成后查看原PD、调参反馈与本次RL的对比，点击「去看回放」直达播放器。曲线下会解释最后两点的变化与采样局限。表格下用恢复次数说明本次策略相对基线的表现，单段回放用来观察一个条件。

页面首屏会显示当前步骤和下一步入口；四步进度条也可跳到已开放的步骤。看完参考自动转到预算。实验历史、新实验和交互仿真位于「实验管理与自由探索」。训练与评测前还会检查本次算力连接，超时或离线时停止提交。任务中断后可在原页点「刷新原实验」或「查看运行记录」。训练失败可以另开实验换算力，评测失败可以查看保留的训练结果。提交状态待核对时，用「接续原请求」继续核对原提交。

8192 步用于熟悉流程，不保证策略提升。正式预算也必须由本轮实际评测判定，不用历史成绩代替。已录制不等于已播放，仿真通过不等于真机资格。

## 换软件继续

关闭窗口或换到另一软件后说：

> 继续

平台恢复当前账号已选实验，保留参数及训练 / 评测来源，不重新提交。有多个历史实验时点“切换实验”卡片选择；不让学员抄 UUID，也不猜全局最新任务。旧版实验仍可选择查看。网页地址可直接分享给有权访问同一实验的账号，不能改变数据归属。

## 快速体验还是正式预算

**快速体验（8,192 步）**适合第一次确认训练、同源评测和回放能走通。前 5,000 步主要收集经验，本次实测到 5,120 步才完成第一批梯度更新。短训可以练流程，恢复次数可能比原 PD 低。

**正式预算（请求 50 万步）**适合判断同一策略能否在固定条件下超过 PD，或开展只改一个参数的对照。训练要占用更久算力，实际步数可能按采样批次对齐。最终看公开组、补充组和收益判据，奖励曲线只用来看训练过程。

## 改一个参数再试

评测完成后点「改一个参数再试」。新实验带入本轮的训练步数、随机种子和侧推上限，原结果仍可打开。可直接选「只把训练步数翻倍」或「只把步数改为正式预算」，也可自定义一项。先检查配方，再确认训练。例如，保留种子与侧推上限，只增加步数，比较两轮在同一条件组的恢复次数。想检查偶然性时，再单独更换随机种子。点击编辑不会启动训练。通过这个入口创建的新实验会记住所用的来源实验，同一账号在 Qoder 或网页重新打开也能接续。评测完成后「跨轮对比」会自动列出本轮和最近两轮来源。旧实验可用「选择历史轮次」手动加入。

表里每行显示训练步数、种子、侧推上限和相对上一轮的变化。恢复次数括号中的正负数是相对上一行的增减。评测协议或基线不同时只显示各轮原始成绩。若多个参数或训练设置同时变化，不能把差值归因给单一参数。

| 课程实测示例（同模型、同算力、种子 7、8.1 N） | 公开组 | 补充组 |
| --- | ---: | ---: |
| 原 PD | 13/31 | 13/31 |

这三轮只改训练步数。正式轮两组都达到课程收益判据，前两轮没有达到。这是一组单种子仿真结果，学员自己的实验仍按实际评测显示。

## 保留自由度

- 打开“自由调整参数”，选择预算、seed 与训练侧推上限。配方确认后才开始。
- 点“新实验”保留原结果，再按新配方实验；不能用原实验改参数。
- 点“暂停后续自动步骤”阻止下一步评测，不取消已经提交的训练；训练结束后可点击“继续同源评测”。关闭窗口也不会取消 Worker。
- 需要助手自动播放时可说“播放本次回放”；沿用 0.5.5 的内置播放计划，先核对当前实验和页面可见性，再记录真实进度，不重交任务。默认课程仍可直接使用页面播放器。
- 随时回聊天问“为什么”“解释这条曲线”“只做评测”或提出其他机器人 / 引擎任务。默认课程不锁住高级工具。仅咨询或说“先别训练”不应启动任务。

## 失败恢复

网络恢复后页面会核对原实验。若还停在提示页，可点「重试读取本轮」。如提示登录，打开平台登录，再点「登录后接续原实验」。重复点击和丢失回包都不重交。页面按同一账号、同一幂等键恢复原 Run；无法核对时显示未知并停止新的提交，可刷新原实验或交维护者恢复。来源不符、任务失败、资源不可用、未登录都如实显示，不换机器或参数凑通过。

## 验证范围

本轮原生验收以交付的验收报告为准。Windows 版 Qoder Desktop 按其官方要求使用 x64。插件的 Node 安装入口也有 ARM64 运行时，但 Windows ARM64 上的 Qoder Desktop 兼容性需另行确认。Windows CI 分别检查安装器、Qoder 本机导入 ZIP、MCP 启动和 DPAPI；原生 Qoder 桌面验收单独记录。本课程仅仿真，不包含真机运动验收。

分发源码与摘要：`provenance.json`、`upstream-provenance.json`、`FILES.sha256`。配置后 `.mcp.json` 会改变，保留原始 ZIP 用于分发和完整性核对。
