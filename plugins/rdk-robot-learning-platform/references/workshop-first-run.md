# 学员首次使用与故障恢复

## 安装只需本系统的入口

解压到最终目录：Windows 双击 `setup-windows.cmd`，macOS 双击 `setup-macos.command`。
首次没有兼容 Node 时，会在当前用户的私人目录准备固定运行时，下载后核对 SHA-256；
不会修改系统 PATH，无须管理员权限或 npm install。网络下载失败会停止并显示原因。

安装器只更新明确的学习平台连接，保留其他 MCP、禁用状态和私有备份。
检测到多条同类连接时先让用户明确选择，不覆盖首条。未安装 Studio 的其他宿主，
导入安装器生成的 `.mcp.json`。移动插件目录后重新运行安装入口。

支持登录继承的 Studio 自动使用当前任务账号。配套登录接线支持 Windows 安装目录与
macOS `.app`，仅接受文件摘要匹配的宿主；Studio 正在运行或版本不兼容时不会强行修改，
也不会停止正在进行的任务。其他宿主通过浏览器授权，登录状态会明确显示账号与模式。

## 没登录过学习平台也能首次授权

已有 Studio／统一账号，无须提前访问学习平台或另行注册学习平台账号。
没有统一账号时先完成注册或账号开通。不要在对话中填写密码、Cookie 或会话文件。

登录不代表获赠算力。课程教师须先给学员分配可见训练资源；插件不会借用其他账号的
模型或 GPU，也不会自动开通计费资源。资源就绪后，首次短训会校验并登记本课程模型，
不再要求账号曾经训练成功。

## 浏览器确认后如何继续（0.5.0）

先调用 `rdk_auth_login` 一次，在浏览器确认当前连接码，再调用 `rdk_auth_status`。
查询状态不会申请新码。待确认授权保存在当前系统用户的私人目录中，MCP 重新连接后
继续领取原授权；Windows 使用当前用户 DPAPI 加密。不要把私人目录或配置后的插件副本转发。
没有待确认授权时，状态只提示调用登录工具；验证码过期后才明确重新发起登录。
网络故障保留原授权，退出插件登录会同时删除会话和待确认记录。

从 0.3.1 升级前，旧进程内尚未领取的验证码没有落盘，无法恢复；升级并刷新实际 MCP
进程后发起一次新授权。核对实际 `pluginRuntime.version=0.5.0` 与 `loadedSourcesMatch=true`，
不要只看插件中心版本号。若仍未登录，记录错误码和认证模式交给维护者，不反复重装或换码。

## 一句话开始

> 帮我做一次 OriginMan 受扰恢复短训练，评测后播放本次回放。

Agent 先实际运行参考仿真，再进行训练、同源评测、查看结果与回放，不让学员编写 UUID 或技术参数。
当账号有多个课程模型或资源时，按名称提供选择；内部标识由工具使用。
固定短训入口为 SAC、8192 步、种子 7、推力 8.1、GPU、仅仿真。
需要正式预算时明确说出训练步数，使用正式训练入口；需要改其他参数时走平台工作台或公开训练提交入口，并按当前 schema 校验；
不能向固定短训工具偷偷传入其他参数，也不自动降级 CPU。

## 失败时如何继续

| 现象 | 应有处理 |
| --- | --- |
| 未登录或会话确实失效 | Studio 在账户菜单登录；其他宿主打开浏览器确认连接码 |
| 网络断开、连接超时、认证服务暂不可用 | 保留登录缓存，提示检查网络；不要求反复退出登录 |
| 没有课程资源 | 明确提示请教师分配，尚未登记模型或提交训练 |
| 多个资源 | 按名称选择，不能自动选首条或切换机器 |
| 提交后网络断开、没有收到 Run ID | 保留实验标识和提交记录，查询原任务，不换键重交 |
| 已收到 Run ID 但保存引用中断 | 从本地提交回执恢复原 Run，只查询，不再次准备资源或提交 |
| 训练失败／被拒绝 | 保留原 Run 和原错误，不自动重试、换机器或改参数 |
| 重复点击或重复要求继续 | 恢复同一实验；不新增训练或评测 |
| 视频已有平台回执但播放器打不开 | 保留数值结果，核对宿主网页登录与原 Worker；不能把链接当作已播放 |

## 怎么判断有无效果

评测只使用本次训练的父 Run、相同参数和同一策略 SHA-256。
分别报告流程是否执行完成、相对 original/tuned 基线的实际结果和回放是否真能播放。
短训练完成不保证效果提升，更不代表可上板。任何缺失证据保持未验证。

## 课程维护者配置与版本核对

安装器会显示插件版本和更新的连接名；新对话调用 rdk_auth_status 核对实际加载版本与认证模式。
多个资源时，教师可使用 `node setup.mjs --connection-name <明确连接名> --resource-id <当前账号可见的课程资源>` 固定课堂资源。
该设置只保存公开资源标识，执行前仍核对账号归属和实时健康；不可见或离线时停止，不改用其他机器。
未配置且有多个资源时，按名称让学员选择一次。分享包不包含任何个人资源绑定。
课程契约不匹配时请教师更新插件；学员不需要自行修改 manifest 或换模型。

## 共用实验页与接续

说“带我完成 OriginMan Workshop。”即可从参考仿真开始，再做本组短训练、同源评测和回放。支持实验会话接口的平台会返回本次实验专属页面，显示真实曲线、比较和播放器；在 Studio 或 Qoder 中继续同一明确实验时，重新验证同一账号并恢复原任务，不重复训练。技术标识在详情中查看，不需要学员抄写。

只有平台已保存实验会话才支持跨客户端接续。旧平台仅保留本机引用，插件会如实标注；不要根据安装版本判断平台功能已部署。支持 MCP Apps 的宿主可显示交互面板，其他宿主打开同一实验页。视频开始播放前保持待验证，短训完成不保证策略优于基线。

## Qoder 安装与账号

Qoder 请使用 `setup-qoder-macos.command` 或 `setup-qoder-windows.cmd`，安装器只配置本插件，不修改 Studio。然后在 Qoder 扩展管理中“添加 → 上传 Plugin”，选择生成的 `Qoder本机导入包.zip`。保留原始分享包；本机包包含绝对路径，不用于转发。详细操作见 [Qoder 首次使用](qoder-first-run.md)。

Qoder 模型服务、插件连接器、平台登录和训练资源分别检查。模型服务没有响应时，不要反复重装平台插件或重置平台登录。通过正常模型请求与真实插件工具调用分别验证，不把网络能连通当成登录成功。

## 查看、保存和跨软件继续

实验页绑定明确训练和评测，不使用“全局最新结果”。曲线来自本次引擎记录；比较表逐组显示原 PD、调参反馈和本次 RL。视频点击播放后才显示正在播放，结束后显示回放已结束。页面窄时可上下滚动，不需要展开技术详情才能看结果。

“保存评测记录”导出 JSON，包含明确任务、参数、同源信息、比较和观察时间；“保存本次视频”保存媒体。需要完整离线图文与嵌入视频时，在原工作台选中本次训练和评测，再使用课程的“导出离线图文与回放”。只看到按钮不代表下载成功，完成后核对保存的文件。

换到另一个软件时，使用同一平台和同一账号，并提供原实验链接，说“继续这个实验，不重新训练”。新平台从服务端恢复明确实验，不依赖原电脑的聊天记录；旧平台仅支持本机接续。不同账号不可互相恢复。

## 测试范围

本版提供 macOS、Windows 安装入口。源码与协议测试不能代替 Windows 实机验收；发行验收记录应单独列明 Windows 是否已实测。OriginMan 本课程只做仿真，不因安装成功、训练完成或评测通过而获得真机运动资格。
