# 学员首次使用与故障恢复

## 安装只需本系统的入口

解压到最终目录：Windows 双击 `setup-windows.cmd`，macOS 双击 `setup-macos.command`。
首次没有兼容 Node 时，会在当前用户的私人目录准备固定运行时，下载后核对 SHA-256；
不会修改系统 PATH，无须管理员权限或 npm install。网络下载失败会停止并显示原因。

安装器只更新明确的学习平台连接，保留其他 MCP、禁用状态和私有备份。
检测到多条同类连接时先让用户明确选择，不覆盖首条。未安装 Studio 的其他宿主，
导入安装器生成的 `.mcp.json`。移动插件目录后重新运行安装入口。

支持登录继承的 Studio 自动使用当前任务账号。配套登录接线支持 Windows 安装目录与
macOS `.app`，仅接受文件摘要匹配的宿主；Studio 正在运行或版本不兼容时不会强行修改，
也不会停止正在进行的任务。其他宿主通过浏览器授权，登录状态会明确显示账号与模式。

## 没登录过学习平台也能首次授权

已有 Studio／统一账号，无须提前访问学习平台或另行注册学习平台账号。
没有统一账号时先完成注册或账号开通。不要在对话中填写密码、Cookie 或会话文件。

登录不代表获赠算力。课程教师须先给学员分配可见训练资源；插件不会借用其他账号的
模型或 GPU，也不会自动开通计费资源。资源就绪后，首次短训会校验并登记本课程模型，
不再要求账号曾经训练成功。

## 一句话开始

> 帮我做一次 OriginMan 受扰恢复短训练，评测后播放本次回放。

Agent 应展示检查、训练、评测、回放四步进度，不让学员编写 UUID 或技术参数。
当账号有多个课程模型或资源时，按名称提供选择；内部标识由工具使用。
固定短训入口为 SAC、8192 步、种子 7、推力 8.1、GPU、仅仿真。
需要改参数时走平台工作台或公开训练提交入口，并按当前 schema 校验；
不能向固定短训工具偷偷传入其他参数，也不自动降级 CPU。

## 失败时如何继续

| 现象 | 应有处理 |
| --- | --- |
| 未登录或会话确实失效 | Studio 在账户菜单登录；其他宿主打开浏览器确认连接码 |
| 网络断开、连接超时、认证服务暂不可用 | 保留登录缓存，提示检查网络；不要求反复退出登录 |
| 没有课程资源 | 明确提示请教师分配，尚未登记模型或提交训练 |
| 多个资源 | 按名称选择，不能自动选首条或切换机器 |
| 提交后网络断开、没有收到 Run ID | 保留实验标识和提交记录，查询原任务，不换键重交 |
| 已收到 Run ID 但保存引用中断 | 从本地提交回执恢复原 Run，只查询，不再次准备资源或提交 |
| 训练失败／被拒绝 | 保留原 Run 和原错误，不自动重试、换机器或改参数 |
| 重复点击或重复要求继续 | 恢复同一实验；不新增训练或评测 |
| 视频已有平台回执但播放器打不开 | 保留数值结果，核对宿主网页登录与原 Worker；不能把链接当作已播放 |

## 怎么判断有无效果

评测只使用本次训练的父 Run、相同参数和同一策略 SHA-256。
分别报告流程是否执行完成、相对 original/tuned 基线的实际结果和回放是否真能播放。
短训练完成不保证效果提升，更不代表可上板。任何缺失证据保持未验证。

## 课程维护者配置与版本核对

安装器会显示插件版本和更新的连接名；新对话调用 rdk_auth_status 核对实际加载版本与认证模式。
多个资源时，教师可使用 `node setup.mjs --connection-name <明确连接名> --resource-id <当前账号可见的课程资源>` 固定课堂资源。
该设置只保存公开资源标识，执行前仍核对账号归属和实时健康；不可见或离线时停止，不改用其他机器。
未配置且有多个资源时，按名称让学员选择一次。分享包不包含任何个人资源绑定。
课程契约不匹配时请教师更新插件；学员不需要自行修改 manifest 或换模型。
