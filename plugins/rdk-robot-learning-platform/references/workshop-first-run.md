# OriginMan 舞蹈 Workshop

1. 在 Studio 启用机器人学习插件并登录。也可直接打开学习平台的 Workshop 页面。
2. 新对话中说「开始 OriginMan Workshop」。可以先播放「交替摆臂」仿真回放。
3. 在「选择参考轨迹」中选预置舞蹈、动作组自由编排，或导入自己的参考轨迹。预览后选择算力并筛查，首次训练可选 8,192 步快检。选卡列表显示已上报的运行和排队数量。
4. 在原 Run 查看进度、评测、仿真回放和 ONNX 策略。点「返回舞蹈 Workshop」可带着当前算力继续。自由编排草稿按账号保存在当前设备，重新打开后先预览和筛查。

通用仿真、训练和设备流程见[插件使用说明](user-guide.md)。
