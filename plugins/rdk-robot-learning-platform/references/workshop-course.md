# OriginMan Workshop 课程范围与下一步

本课学习在仿真中让 OriginMan 保持站立并在侧推后恢复，观察训练预算与结果的关系。不是行走或跑跳课，也不包含真机部署、板端动作和真实遥测回流。平台具备通用硬件工具，不表示本课程制品可以直接上真机。

## 学员路径

1. **观察参考仿真**：先看课程参考效果，标注这是参考制品，不是自己刚训练的模型。
2. **训练本组策略**：复用 Studio 当前账号，检查指定课程资源。学员无需输入工具名或 UUID。8192步是快速流程检查，不保证改善；50万步是效果实验预算，不能擅自延长或换机器。
3. **同源仿真评测**：读取本轮权重，在相同固定扰动下对比原PD、调参反馈与本次RL。训练和评测是不同phase的Run，总记录数不是成功训练数，completed不是学会。
4. **回放与保存**：打开本次评测视频，提供本次视频与评测JSON保存入口。需要主工作台的离线图文导出时，先重新核对所选训练和评测，不能导出全局最新结果代替。没有宿主播放或下载回执时明确未验证，不用参考视频冒充本轮。
5. **单变量调参**：先解释成功或失败条件。学员要求继续时保留原实验，复制参数新建实验，只改变训练步数或训练侧推上限；固定评测条件不变，比较两轮来源和结果。不自动换seed或重训直到看起来成功。

## 中断后从哪里继续

已提交的任务继续读取原Run。引用保存失败与训练失败是不同问题；回执中submitted=true且有runId时停止新的提交，只读查询原任务及已有结果，不需要重训。无确定引用或身份不匹配时停止并交维护者恢复，不猜最新记录、不绕过权限、不自动重交。

训练完成而评测尚未提交，下一步才是同源仿真评测；评测完成后进入本轮结果、回放与保存；学员要求优化才进入新实验。不要推荐部署预检，也不要把真机部署缺失当成本课未完成。

## 学员看到的表达

默认只展示“当前进度、本次结果、下一步”。例如：“本轮评测完成，这次未超过参考控制器。先打开本次回放，看一下跌倒条件。”技术ID、错误码与日志放在可展开详情。已完成的查询不需要再次请求许可；新训练遵守原请求的预算，调参新实验需有学员明确意图。

需要能力介绍时，先说本课能做什么，再用一句话区分平台扩展能力。不要为解释能力搜索无关文档或罗列大量台账。平台全局golden_path不是本课进度；账号同步、Worker在线、开发机SSH和nativeCompute分别报告，不从一个状态推断另一个状态。
