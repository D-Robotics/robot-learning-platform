# OriginMan 舞蹈 Workshop 课程范围

学员可以选择整套预置舞蹈，或从空作品挑选动作组并调整顺序、节拍和强度。先看动作示意，再选 GPU 和训练预算。8192 步用于检查链路，50 万步用于正式实验，质量按本轮评测判断。

提交后按原 Run 查看训练进度、真实评测、仿真回放和策略文件。网络中断时先查询原 Run。改参是在确认后提交一条新运行，保留原结果。

从[舞蹈 Workshop 教程](workshop-first-run.md)开始。旧受扰恢复实验属于历史记录，核对原 Run 和原账号后查看留存结果。关于旧结果的指标口径可查[历史预算与证据](workshop-training-evidence.md)。
