这是 **通用机器人学习插件**，在 Studio、Qoder 和支持 MCP 的宿主里连接同一套学习平台。可以按机型和任务做仿真、录制、强化学习、模仿学习、评测、回放与部署预检。OriginMan 舞蹈和受扰恢复是可选任务。机型、引擎和设备能力以当前平台的可用适配器为准。

Qoder 用户请先读 references/qoder-first-run.md，运行 setup-qoder-macos.command 或 setup-qoder-windows.cmd，仅配置本插件，不改 Studio，并生成Qoder本机导入包.zip。桌面请上传这个本机包，不要上传未配置的原ZIP。新机器人说：先离线，请逐题引导我输入。

Studio 用户：解压到最终目录后，Windows 双击 setup-windows.cmd，macOS 双击 setup-macos.command。
安装器自动准备兼容 Node、校验下载摘要、生成配置，并接入已初始化的 Studio。
不需要平台源码、npm install、手写密码或 Cookie。其他宿主导入生成的 .mcp.json。
完整插件使用说明见 [references/user-guide.md](references/user-guide.md)；Workshop 页面教程见 references/workshop-first-run.md。

支持登录继承的 Studio 自动复用当前任务账号；配套接线适配 Windows/macOS 安装路径，
只修改文件摘要匹配的宿主，并保留备份。不停止正在进行的任务；版本不兼容不强行覆盖。
其他宿主仅访问平台数据时使用 rdk_auth_login 打开浏览器确认，再调用 rdk_auth_status；本地课堂知识与证据字段检查无需平台登录。

已有统一账号，无须提前访问学习平台。首次训练不依赖成功历史；资源就绪后按需登记课程模型。
教师须先分配学员可见的计算资源；插件不会借用其他账号资源或自动开通计费算力。

首次可以说 **打开机器人学习工作台** 或 **带我做一次强化学习**。有明确机型或任务就直接沿用。要体验课程时可说 **开始 OriginMan 受扰恢复 Workshop**，或 **训练 OriginMan 跳舞**。

- OriginMan 舞蹈使用独立 78→18 契约、`originman-dance-ppo` 和 PPO 仿真入口，不复用平衡/受扰恢复参数。资源与引擎检查失败时停止，不改跑恢复任务。
- 每次训练提交、等待和状态查询都带本轮 Run 的平台链接；Qoder 会打开并置前内置页面，其他宿主可点击链接。只读详情页直接按 Run ID 查询当前账号可见的运行、编排、曲线与质量门；找不到时说明账号无权访问或记录不存在。
- 舞蹈 Run 详情页按 Run ID 展示配置、训练曲线和风格质量门；只有平台返回同源且绑定本 Run 的视频链接，并通过策略/轨迹摘要核对时才显示回放。训练完成、风格质量通过和视频实际播放分别报告。当前舞蹈流程不提供真机部署。

常规恢复课程在页面看参考、选预算，随后自动训练并做同源评测。开始只准备课程，不默认开训。

- “继续”：同一账号在 Studio / Qoder 恢复当前已选实验，不用抄 ID；多个候选用卡片选择。
- “看看效果”：直接进入本次曲线、对比和播放器。曲线滑杆可查看真实采样点；播放、刷新和保存都是页面操作。
- 自由参数：可在页面选 8192 快检、50 万步或自定义预算 / seed / 侧推；正式或自定义先确认配方。新实验保留旧结果。
- “暂停后续自动步骤”不取消已提交任务；高级训练、其他机器人、解释与资料请求仍可用自然语言或原子工具完成。

快速体验不保证质量提升。训练完成、收益判据和回放播放分开显示；只有实际播放后才称已播放。按钮工作台需要支持 `/api/v1/duck/workshop-sessions` 的新版平台；旧平台会明确提示升级，不退回隐式开训。

网络异常保留登录；断线、超时与重复点击不重交。重启后按同一实验引用恢复原 Run。
评测核对父 Run 与策略摘要；completed 不等于学会，链接也不等于视频已经播放。

底层便携核心来源见 upstream-provenance.json，扩展摘要见 provenance.json，文件摘要见 FILES.sha256。
原始分享包不含凭据；配置后含本机路径，不要把配置后的私人副本再分发。

支持实验会话API的平台可在同一账号下跨 Studio、Qoder 和浏览器恢复本次实验，并打开共用实验页查看真实曲线、同源对比与回放。旧平台明确保留本机接续范围，不声称跨机器同步。
